# Resume Keyword Analyzer

A simple Java program that compares resume keywords with a job description to identify matched and missing keywords.

## Features
- Reads resume and job description from text files.
- Removes stop words.
- Counts keyword frequency.
- Identifies matched and missing keywords.
- Calculates keyword match percentage.
- Sorts missing keywords based on frequency.

## Technologies Used
- Java
- HashMap
- HashSet
- File Handling
- Collections Framework

## How It Works
1. Reads the resume and job description files.
2. Removes stop words and cleans the text.
3. Extracts and counts keywords from the job description.
4. Compares keywords with the resume.
5. Displays matched percentage and missing keywords.

## Output
- Keyword match percentage.
- Matched keyword count.
- Missing keywords with frequency.
